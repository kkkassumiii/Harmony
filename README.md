# Гармония с собой

Веб-приложение для психологической поддержки, самонаблюдения и личного развития.

## 📋 Описание проекта

**Гармония с собой** — это современное веб-приложение, которое помогает пользователям:
- Отслеживать эмоциональное состояние через дневник эмоций
- Вести журнал заметок и переживаний  
- Устанавливать и достигать личные цели
- Формировать полезные привычки
- Просматривать статистику и аналитику эмоционального состояния
- Получать персонализированные рекомендации для улучшения самочувствия

### Установка и запуск

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd harmony

# Запустите проект с Docker
docker-compose up -d

# Инициализируйте БД (в отдельном терминале)
docker-compose exec backend npm run db:migrate
docker-compose exec backend npm run db:seed
```

Приложение будет доступно:
- **Фронтенд**: http://localhost:3000
- **Бэкенд API**: http://localhost:8000
- **API Docs**: http://localhost:8000/api/docs

## 🔑 Основные функции

### Аутентификация
- Регистрация новых пользователей
- Вход в систему с помощью JWT
- Безопасное хранение паролей (bcrypt)
- Сессия пользователя

### Дневник эмоций
- Создание, редактирование, удаление записей
- Выбор эмоции и уровня настроения
- Добавление тегов и заметок
- Просмотр истории эмоций

### Аналитика и рекомендации
- График тренда настроения на главной панели
- Среднее значение настроения и количество записей
- Топ эмоций по частоте использования
- Персональные рекомендации на основе последних данных

## Как это работает
- Фронтенд получает данные из защищённых API `/api/analytics` и `/api/analytics/recommendations`
- Сервер собирает статистику по записям эмоций, целям и привычкам
- Клиент визуализирует тренды с помощью `Chart.js`
- Алгоритмы рекомендаций формируют советы на основе среднего настроения, активности привычек и целей

### Цели и привычки
- Создание и отслеживание целей
- Добавление привычек
- Отметка выполнения
- Статистика прогресса

### Аналитика
- Графики эмоционального состояния
- Статистика целей и привычек
- История активности
- Отчеты за период

## 📚 API Документация

Введите в браузер: http://localhost:8000/api/docs

Полная документация всех endpoints доступна через Swagger/OpenAPI.

### Примеры запросов

#### Регистрация
```bash
POST /api/auth/register
Content-Type: application/json

{
  "email": "user@example.com",
  "username": "username",
  "password": "password123"
}
```

#### Вход
```bash
POST /api/auth/login
Content-Type: application/json

{
  "username": "username",
  "password": "password123"
}
```

#### Добавить запись эмоции
```bash
POST /api/emotion-entries
Authorization: Bearer TOKEN
Content-Type: application/json

{
  "emotionId": "uuid",
  "content": "Today was a good day",
  "moodLevel": 8,
  "tags": "positive, productive"
}
```

#### Получить аналитику настроения
```bash
GET /api/analytics
Authorization: Bearer TOKEN
```

#### Получить рекомендации
```bash
GET /api/analytics/recommendations
Authorization: Bearer TOKEN
```
